# Linux 服务器实验记录

从零开始搭一台云服务器：在 Windows 上装 Linux 环境、开通云主机、配置密钥登录、部署脚本。

## 这个仓库是什么

这是我学习运维（Linux / 云原生方向）的实操记录。**不是教程，是我自己动手做完之后的记录**——命令、报错、踩过的坑都在里面。

## 做了什么

- 在 Windows 上用 WSL2 装好 Ubuntu 24.04
- 开通一台阿里云轻量应用服务器（Ubuntu 24.04 / 2 核 2G），配置好 SSH 密钥登录
- 写了第一个 Shell 脚本 `check.sh`：一条命令输出时间、内存、磁盘
- 用 `scp` 把脚本传到服务器上运行，验证它在真实服务器上的表现
- 安全加固：关闭 SSH 密码登录，只允许密钥登录

## 环境

- 本地：Windows 11 + WSL2 + Ubuntu 24.04
- 服务器：阿里云轻量应用服务器 / Ubuntu 24.04 / 2 vCPU / 2 GiB 内存 / 40 GiB 系统盘

## 踩过的坑（部分）

- `wsl --install` 下载 Ubuntu 失败（`0x80072f78`），重试后成功
- 粘贴命令时带进了不可见字符，导致 `command not found`——用 `history | grep` 查出真相
- 脚本报 `Permission denied`：文件没有执行权限，需要 `chmod +x`
- 脚本没写 `#!/bin/bash`，文件里的英文句子被当成命令执行

完整的踩坑记录见 `setup-notes.md`。
