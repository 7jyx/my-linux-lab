# Linux 服务器运维实验

从零开始搭一台云服务器：装 Linux 环境、配置密钥登录、写自动化脚本、部署网站。

## 这个仓库是什么

这是我学习运维（Linux / 云原生方向）的实操记录。**不是教程，是我自己动手做完之后的记录**——命令、报错、踩过的坑都在里面。

## 做了什么

- 在 Windows 上用 WSL2 装好 Ubuntu 24.04，建立本地实验环境
- 开通云服务器（腾讯云轻量 · Ubuntu 24.04 · 2 核 2G · 广州），配置 SSH 密钥登录
- 编写三个 Shell 脚本：系统巡检、自动备份、过期备份清理
- 用 `crontab` 配置定时任务（每天 2:00 备份、3:00 清理），实现无人值守
- 部署 Nginx 并发布静态站点，实现公网访问
- 完成服务器安全加固：**禁用 SSH 密码登录，只允许密钥认证**
- 完成一次服务器迁移：从阿里云迁到腾讯云，1 小时内重建整套环境

## 踩过的坑（部分）

- 粘贴命令带进了不可见字符，导致 `command not found` —— 用 `history | grep` 查出真相
- 脚本报 `Permission denied`：文件没有执行权限，需要 `chmod +x`
- 脚本没写 `#!/bin/bash`，文件里的英文句子被当成命令执行
- 中文输入法打出的**全角斜杠**，导致路径找不到（tar 报 `Cannot stat`）
- 改 SSH 配置不生效：`sshd_config.d/` 里的文件**优先级高于**主配置文件
- 定时任务测试时设成"每分钟"，忘记改回 —— 差点让日志撑满磁盘

完整的踩坑记录见 `setup-notes.md`。
